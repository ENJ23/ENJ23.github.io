# ENJ23.github.io.

## Descripción de Archivos y Carpetas

### `index.html`
La página principal del sitio web. Contiene:
- Una barra de navegación con enlaces a otras secciones del sitio.
- Un video de fondo en la sección "Hero".
- Secciones adicionales como "Nuestras Clases".

### `/Styles/`
Contiene los estilos CSS para el diseño del sitio:
- `indexStyle.css`: Estilos específicos para la página principal.
- `navbar.css`: Estilos para la barra de navegación.
- `darklight.css`: Estilos para el cambio entre modo oscuro y claro.

### `/Tp1/`
Carpeta que agrupa recursos adicionales, como estilos específicos, imágenes y videos.

### `/videos/`
Carpeta que almacena los videos utilizados en el sitio, como el video de fondo en la página principal.

### `/images/`
Carpeta que contiene imágenes utilizadas en el diseño del sitio.

## Cómo ejecutar el proyecto
1. Clona este repositorio en tu máquina local.
2. Abre el archivo `index.html` en tu navegador o utiliza un servidor local (como Live Server en VS Code) para visualizar el sitio.
3. Asegúrate de que todos los recursos (videos, imágenes, etc.) estén en las rutas correctas.

## Notas
- El sitio está diseñado para ser responsivo y funciona en dispositivos móviles y de escritorio.
- Si el video de fondo no se reproduce, verifica que el archivo esté en la carpeta `/videos/` y que la ruta en el código sea correcta.
